# 🤝 AI 팀룸 (프로토타입)

팀원 각자가 자기 AI(Claude, ChatGPT, Gemini)와 작업하는 과정을 한 화면에서 실시간으로 공유하는 팀플 협업 도구입니다.

## 실행

```bash
npm install
npm start
```

→ http://localhost:3000 에서 방을 만들고, **🔗 초대 링크**를 팀원에게 보내면 됩니다.
(같은 와이파이의 다른 기기라면 `localhost` 대신 이 PC의 IP를 사용하세요.)

## 💻 Claude Code · Codex 커넥터
터미널이나 앱에서 쓰는 Claude Code와 Codex 대화를 자동으로 공유합니다. 팀 프로젝트 폴더의 대화만 올라갑니다.
- 파일: `connector/teamroom-connector.mjs`
- 사용법: [connector/사용법.md](connector/사용법.md)
- 테스트: `node tools/connector-test.mjs http://localhost:3000`

## 🧩 크롬 확장 (추천): 평소 쓰는 크롬에서 자동 공유

구글 계정 로그인을 포함해 ChatGPT, Claude, Gemini 모두 쓸 수 있는 방식입니다.
- 소스: `extension/`
- 배포용 zip: `dist/AI팀룸-크롬확장.zip`
- 설치와 사용법: [친구-테스트-가이드.md](친구-테스트-가이드.md)

동작:
- `content.js`가 AI 페이지의 대화를 읽고, `background.js`가 공유 규칙을 판단해 서버로 전송합니다. 오프라인일 때는 대기열에 보관했다가 다시 보냅니다.
- `sidepanel`이 팀룸 화면을 크롬 오른쪽에 보여줍니다.

자동 테스트 (실제 크롬에 확장을 설치하고 가짜 AI 페이지로 확인):
```bash
cd tools/ext-test && npm install && node test.mjs http://localhost:3000
```

**다른 사람이 접속하려면** 서버가 외부에서 열려야 합니다.
- 같은 와이파이: `http://이PC의IP:3000`
- 임시 공개 주소: `cloudflared tunnel --url http://localhost:3000`
- 계속 쓸 때: 클라우드 배포

임시 공개 주소처럼 실시간 스트림이 막히는 환경에서는 화면이 자동으로 1.5초 간격 갱신으로 전환됩니다.

## 🖥️ 데스크톱 앱 (AI팀룸.exe): 구글 계정을 쓰지 않는 경우

`desktop/dist/AI팀룸.exe`를 실행하면 됩니다. 설치 없이 바로 실행되는 단일 파일입니다.

1. 처음 실행하면 팀장에게 받은 **초대 링크**를 붙여넣고, 오른쪽 팀룸 패널에서 이름을 입력해 입장합니다.
2. 왼쪽에서 ChatGPT, Claude, Gemini에 **평소처럼 로그인**합니다. 각자 쓰는 구독을 그대로 쓰고, API 키는 필요 없습니다.
3. 그냥 대화하면 됩니다. 답변이 생성되는 동안에도 팀원 화면에 실시간으로 표시됩니다.
4. 팀원 피드백의 **↪ 피드백 반영**을 누르면 왼쪽 AI 입력창에 피드백이 자동으로 입력됩니다. 전송은 직접 누릅니다.

**공유 규칙**
- 상단 **● 팀에 공유 중** 토글이 켜져 있을 때, AI가 실제로 답변을 생성한 대화만 공유됩니다. 예전 대화를 열어보기만 하면 공유되지 않습니다. 필요하면 **지금 공유** 버튼으로 직접 공유할 수 있습니다.
- 한 번 공유된 대화는 이어서 나누는 내용도 계속 공유됩니다.
- 원본 앱(ChatGPT 등)에서 대화를 지워도 **팀룸에 공유된 내용은 유지**됩니다.

**껐다 켜도 유지되는 것**
- AI 로그인 상태와 공유 설정은 내 PC(`%APPDATA%/AI팀룸`)에 저장됩니다.
- 공유된 대화, 피드백, 문서는 팀룸 서버에 저장됩니다.
- 인터넷이 끊겼을 때 못 보낸 내용은 내 PC 대기열에 저장했다가, 다시 연결되면 자동으로 보냅니다.

**개발 및 빌드**
```bash
cd desktop
npm install
npm start          # 개발 실행
npm run dist       # dist/AI팀룸.exe 생성
```
자가 테스트: 환경변수 `TEAMROOM_TEST=1`, `TEAMROOM_ROOM_URL=<팀룸 링크>`를 설정하고 실행하면, 가짜 AI 페이지(`/mock-ai.html`)로 공유, 피드백 삽입, 오프라인 보관까지 자동으로 확인합니다.

> ⚠️ ChatGPT, Claude, Gemini의 화면 구조가 바뀌면 대화를 읽는 부분(`desktop/preload/ai-preload.js`의 `SITES`)을 수정해야 합니다.

## 기능

| 기능 | 설명 |
|---|---|
| 실시간 AI 작업 공유 | 팀원별 칼럼에서 각자의 AI 대화가 글자 단위로 실시간 표시됩니다. |
| 메시지 단위 피드백 | AI 답변에서 문장을 드래그한 뒤 **💬 피드백**을 누르면 인용과 함께 그 팀원에게 전달됩니다. |
| 피드백 반영 | 받은 쪽에서 **↪ 피드백 반영**을 누르면 피드백이 AI 요청문으로 자동 작성되고, 보낸 뒤 "AI에 반영됨"으로 표시됩니다. |
| 공동 문서 | **📄 문서로 보내기**로 AI 답변을 모읍니다. 출처(누구의 어떤 AI)가 남고, 편집·순서 변경·.md 다운로드를 지원합니다. |
| 과제 보드 | 할 일, 담당자, 상태(할 일 → 진행중 → 완료, 클릭으로 변경)를 관리합니다. |
| 기여 로그 | AI 요청 수, 문서 기여, 피드백 주고받은 내역, 활동 타임라인을 자동으로 집계합니다. |

## API 키가 없어도 쓰는 방법 (우선순위 순)

1. **개인 키**: ⚙️ 설정에서 입력합니다. 이 브라우저의 localStorage에만 저장되고, 요청할 때만 서버를 거칩니다.
2. **팀 공용 키**: 방장(👑)이 ⚙️ 설정에서 등록합니다. 키가 없는 팀원도 쓸 수 있습니다. 서버 메모리에만 저장되며 다른 팀원에게는 보이지 않고, 서버를 재시작하면 사라집니다.
3. **서버 키**: 서버를 실행할 때 환경변수 `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`를 넣어두면 모든 방에서 쓸 수 있습니다.
4. **데모 모드**: 키 없이 가짜 AI 응답으로 기능만 체험합니다.

## 구조

- `server.js`: Node 서버. 방 상태 관리, SSE 실시간 전송, AI 호출 프록시(Claude는 Anthropic SDK, OpenAI와 Gemini는 REST 스트리밍)를 담당합니다.
- `public/`: 프론트엔드(빌드 없음, 순수 JS)
- `data/`: 방별 JSON 저장소. API 키는 저장하지 않습니다.

## 프로토타입 한계 (실서비스 전 필요한 것)

- 로그인 없음: 초대 링크를 아는 사람은 누구나 입장할 수 있습니다.
- 공동 문서는 블록 단위로 마지막에 저장한 내용이 적용됩니다(구글 독스식 동시 편집은 Yjs 등으로 교체 필요).
- 팀 공용 키 사용량 제한이 없습니다.
- 기본 모델명은 설정에서 바꿀 수 있습니다. OpenAI와 Gemini 모델명은 계정에서 쓸 수 있는 이름으로 확인하세요.

🤝 AI 팀룸 연결하기

PC에 설치해서 쓰는 AI 앱(Claude Code · Codex/ChatGPT 앱 · Claude 앱의 채팅)에서 나눈 대화를 팀룸에 공유하는 설정입니다. 5분이면 끝나요. (Windows 기준)

1 Node.js 확인

PowerShell(터미널)을 열고 입력하세요.

node -v

v18 이상이 나오면 됩니다. 안 나오면 nodejs.org 에서 LTS 버전을 설치한 뒤 터미널을 다시 여세요.

2 파일 두 개 받기

새 폴더를 하나 만들고(예: 바탕화면의 ai-teamroom), 아래 두 파일을 같은 폴더에 저장하세요.

① 커넥터 (teamroom-connector.mjs) ② 팀룸 창 (AI팀룸.exe · 105MB) 사용법.md

이 폴더는 설치 후에도 지우지 마세요. 팀룸 창(AI팀룸.exe)을 이 폴더에서 실행합니다.

브라우저나 Windows가 "위험할 수 있는 파일"이라고 경고하면 계속 → 유지를 누르세요. 서명이 없는 프로그램이라 나오는 경고입니다.

3 설정하기

파일을 저장한 폴더에서 터미널을 열고(폴더 빈 곳에서 Shift+우클릭 → "터미널에서 열기") 아래 명령을 실행하세요.


    
차례로 물어봅니다.

    
    
      
  • 이름 — 팀룸에 보일 이름
    • 
      
  • 공유할 팀 프로젝트 폴더 — Claude Code·Codex를 쓰는 프로젝트 폴더 경로 (여러 개는 ; 로 구분)
    • 
      
  • 패널 앱 경로 — 그냥 Enter (같은 폴더의 AI팀룸.exe를 자동으로 찾습니다)
    • 
      
  • 자동 실행 — Y 를 누르면 윈도우를 켤 때 알아서 실행됩니다
    • 
    

  


  

    
4 실행하기

    
폴더의 AI팀룸.exe를 더블클릭하세요. 화면 오른쪽에 팀룸 창이 뜨고, 대화를 공유하는 커넥터도 함께 켜집니다. 터미널을 켜 둘 필요는 없어요.

    
Windows가 "PC 보호" 경고를 띄우면 추가 정보 → 실행을 누르세요. 잘 켜졌는지는 팀룸 창 메뉴 공유 → 대화 공유 관리… 아래쪽의 "● 커넥터 실행 중"으로 확인할 수 있습니다.

  


  

    
5 확인하기

    
    
      
  • 팀 프로젝트 폴더에서 Claude Code나 Codex로 질문을 보냅니다.
    • 
      
  • 화면 오른쪽 위에 "이 대화를 팀룸에 공유할까요?" 창이 뜨면 공유하기를 누릅니다. (고르기 전에는 아무것도 올라가지 않아요)
    • 
      
  • 화면 오른쪽의 팀룸 창에 내 대화가 올라오면 성공입니다.
    • 
    

    
팀 폴더가 아닌 곳의 대화, 그리고 "비공개"로 고른 대화는 공유되지 않습니다.

  


  

    
6 앱마다 공유하는 방법

    
팀룸 창 메뉴 공유 → 대화 공유 관리…에 내 대화 목록이 나옵니다. 공유할 대화의 공유하기만 누르면 돼요.

    
    
      
  • Claude Code (터미널 · Claude 앱의 Code 탭) — 팀 폴더의 새 대화는 자동으로 물어보고, 다른 폴더·예전 대화는 목록에서 골라 공유합니다.
    • 
      
  • Codex · ChatGPT 앱 — Claude Code와 같습니다.
    • 
      
  • Claude 앱의 "채팅" 탭 — 앱 화면에 열어 본 대화가 목록의 "Claude 앱 채팅"에 나타납니다. 새 글을 주고받으면 공유할지 물어봐요. 공유 중인 대화는 앱 화면에 열려 있는 동안 올라갑니다.
    • 
      
  • 브라우저로 쓰는 ChatGPT · Claude · Gemini — 아래 크롬 확장을 설치하세요.
    • 
    

  

  
🧩 웹에서 쓰는 경우: 크롬 확장

  
chatgpt.com · claude.ai · gemini.google.com 에서 나눈 대화를 공유하려면 크롬 확장을 설치하세요. (크롬·엣지·웨일)


  

    
1 확장 파일 받기

    
크롬 확장 받기 (zip)

    
받은 zip의 압축을 풀어 지우지 않을 곳에 두세요. (폴더를 지우면 확장도 사라집니다)

  

  

    
2 크롬에 넣기

    
    
      
  • 주소창에 chrome://extensions 입력 (엣지는 edge://extensions)
    • 
      
  • 오른쪽 위 개발자 모드 켜기
    • 
      
  • 압축해제된 확장 프로그램을 로드합니다 → 압축을 푼 AI팀룸-크롬확장 폴더 선택
    • 
    

  

  

    
3 연결하고 사용하기

    
    
      
  • chatgpt.com (또는 claude.ai, gemini.google.com)을 열면 화면 오른쪽에 팀룸이 붙습니다.
    • 
      
  • 처음 한 번, 아래 초대 링크를 붙여넣고 연결 → 이름을 넣고 입장합니다.
    • 
    

    

    
    
      
  • 새 대화를 시작하면 "이 대화를 팀룸에 공유할까요?" 카드가 뜹니다. 공유하기를 누른 대화만 올라가요.
    •

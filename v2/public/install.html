🤝 AI 팀룸 v2 설치

Claude Code · Codex(ChatGPT 앱) · Claude 앱을 쓸 때 옆에 뜨는 팀룸 창입니다. 앱 하나만 받으면 되고, 터미널이나 Node.js 설치는 필요 없어요. (Windows)

1 앱 받기

AI팀룸v2.exe 받기 (약 105MB)

지우지 않을 폴더(예: 바탕화면의 AI_TeamRoom)에 저장하세요. 예전 버전(AI팀룸.exe)과 같이 있어도 서로 섞이지 않습니다.

브라우저가 "위험할 수 있는 파일"이라고 하면 계속 → 유지, 실행할 때 "PC 보호"가 뜨면 추가 정보 → 실행을 누르세요. 서명이 없는 프로그램이라 나오는 경고입니다.

2 실행하고 한 번만 설정

AI팀룸v2.exe를 더블클릭하면 "시작하기" 화면이 뜹니다. 세 가지만 넣으세요.

  • 초대 링크 — 아래 링크를 복사해 붙여넣기

    
    
      
  • 이름 — 팀룸에 보일 이름
    • 
      
  • 팀 프로젝트 폴더 — Claude Code·Codex로 팀 작업을 하는 폴더 (나중에 메뉴 현황 → 팀 프로젝트 폴더 추가…로도 가능)
    • 
    

    
시작하기를 누르면 화면 오른쪽에 팀룸 창이 뜹니다. 다음부터는 exe만 실행하면 돼요.

  


  

    
3 대화 공유

    
    
      
  • 평소처럼 Claude Code · Codex · Claude 앱 채팅을 쓰면 "이 대화를 팀룸에 공유할까요?"가 뜹니다. 공유하기를 누른 대화만 올라가요.
    • 
      
  • 예전 대화·다른 폴더의 대화는 메뉴 공유 → 대화 공유 관리…에서 골라 공유합니다.
    • 
    

  


  

    
4 프로젝트 현황 · 브랜치

    
    
      
  • 팀룸 위쪽 📊 프로젝트 현황에 작업 흐름도와 브랜치(원격 · 각자 PC)가 나옵니다.
    • 
      
  • 브랜치는 팀 프로젝트 폴더가 git 저장소면 자동으로 올라옵니다. 따로 할 일이 없어요.
    • 
      
  • 작업 흐름도를 AI가 직접 채우게 하려면 메뉴 현황 → AI가 현황을 적도록 안내 넣기…를 누르세요. 새 파일을 만드는 방식이고, 넣은 안내 되돌리기…로 언제든 원래대로 돌릴 수 있습니다.

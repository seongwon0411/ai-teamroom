# AI 팀룸 v2를 클라우드에 올리기

오라클 클라우드 무료 VM에 팀룸 서버를 올리는 순서입니다. 올리고 나면 주소가 고정되고, 본체를 꺼도 팀룸이 계속 열려 있습니다.

## 1. 오라클 콘솔에서 할 일 (한 번)

콘솔 메뉴 이름은 바뀔 수 있으니, 아래 이름과 비슷한 것을 찾으면 됩니다.

1. **VM 만들기** — Compute → Instances → Create instance
   - Image: **Ubuntu** (22.04 또는 24.04)
   - Shape: "Always Free" 표시가 붙은 것 아무거나 (가장 작은 것으로 충분)
   - SSH keys: **Generate a key pair** → **Save private key** 로 `.key` 파일을 내려받아 둡니다. 이 파일은 다시 받을 수 없어요.
   - Public IP가 배정되게 둡니다.
2. **포트 열기** — VM 상세 화면 → Subnet → Security List → Add Ingress Rules
   - Source `0.0.0.0/0`, TCP, Destination port **80**
   - Source `0.0.0.0/0`, TCP, Destination port **443**
   - (22번은 기본으로 열려 있습니다)
3. VM의 **Public IP 주소**를 적어 둡니다.

## 2. 도메인 (선택)

- 도메인이 **없으면** 아무것도 안 해도 됩니다. 스크립트가 `1-2-3-4.sslip.io` 같은 무료 주소를 자동으로 씁니다.
- 도메인이 **있으면** 도메인 관리 화면에서 A 레코드를 VM의 Public IP로 연결해 둡니다.

## 3. 본체에서 올리기

`cloud` 폴더의 **`클라우드에-올리기.bat`** 을 더블클릭합니다. 처음에만 네 가지를 묻습니다.

| 질문 | 넣을 것 |
|---|---|
| VM의 공인 IP 주소 | 1번에서 적어 둔 Public IP |
| 개인 키 파일 | 내려받은 `.key` 파일을 창에 끌어다 놓고 Enter |
| VM 사용자 이름 | 그냥 Enter (`ubuntu`) |
| 도메인 | 없으면 그냥 Enter |

그다음 "본체의 방 내용도 옮길까요?"에 Enter를 누르면 지금 방들이 그대로 옮겨집니다.

끝나면 화면에 **팀룸 주소**와 **방 만들기 비밀번호**가 나옵니다. 비밀번호는 적어 두세요.

## 4. 올린 뒤

1. 브라우저에서 새 주소가 열리는지 확인합니다.
2. 팀룸 창 메뉴 **방 → 방 바꾸기 · 새 방 만들기…** 의 "초대 링크로 들어가기"에 새 링크를 넣습니다.
   예전 방은 방 ID가 그대로라 `https://새주소/?room=방ID` 입니다.
3. 팀원에게 새 링크를 전달합니다. 이제 주소는 바뀌지 않습니다.
4. 각 방에 **방 비밀번호**를 겁니다 (팀원 줄 끝의 `🔓 비밀번호 없음`). 팀원 모두가 최신 `AI팀룸v2.exe`를 받은 뒤에 거세요.
5. 본체의 `팀룸v2-서버-켜기.bat`은 더 이상 켜지 않아도 됩니다.

## 나중에 쓰는 것

| 하고 싶은 일 | 방법 |
|---|---|
| 서버를 새 버전으로 바꾸기 | `클라우드에-올리기.bat` 다시 실행 (방 내용은 그대로) |
| 방 내용 백업을 본체로 받기 | `클라우드-백업-받기.bat` → `cloud\backups` 폴더 |
| VM 주소나 키를 바꿨을 때 | `cloud\cloud-settings.json` 을 지우고 다시 실행 |
| 방 만들기 비밀번호 다시 보기 | VM에서 `sudo cat /opt/teamroom/data/create-password.txt` |
| 방 만들기 비밀번호 바꾸기 | 그 파일 내용을 바꾸면 바로 적용 |

VM 안에서도 매일 새벽 4시에 백업이 만들어지지만(14일치), VM 자체가 회수되면 같이 사라집니다. **가끔 `클라우드-백업-받기.bat`으로 본체에 받아 두세요.**

## 안 될 때

- **파일을 보내지 못했다고 나옴** → IP 주소와 키 파일이 맞는지, VM이 Running 상태인지 확인합니다.
- **서버는 켜졌는데 https 주소가 안 열림** → 1-2번의 80·443 포트 규칙, 도메인이 VM IP를 가리키는지 확인합니다. 인증서 발급에 1~2분 걸릴 수 있습니다.
- **sslip.io 주소로 인증서가 안 나옴** → 무료 주소는 발급 한도에 걸릴 수 있습니다. 도메인을 준비해 `cloud-settings.json`을 지우고 다시 올리세요.

## VM에 설치되는 것

- Node.js 22, Caddy (HTTPS 인증서 자동 발급·갱신)
- 서버 파일: `/opt/teamroom` (방 내용은 `/opt/teamroom/data`)
- 자동 시작 서비스 `teamroom` — VM이 재부팅돼도 저절로 켜집니다
- 서버는 VM 안에서만 열려 있고(127.0.0.1), 밖에서는 HTTPS로만 들어옵니다

# AI 팀룸 커넥터 사용법: Claude Code · Codex 대화 자동 공유

Claude Code와 Codex(터미널·앱 모두)에서 나눈 대화를 팀룸에 자동으로 올립니다.
Claude Code와 Codex의 설정은 건드리지 않고, 두 도구가 내 PC에 남기는 대화 기록 파일을 읽어서 올리는 방식입니다.

## 필요한 것
- Node.js 18 이상 (터미널에서 `node -v`로 확인)
- 팀장에게 받은 팀룸 초대 링크
- 파일 `teamroom-connector.mjs` 하나

## 1. 처음 설정 (한 번)
```bash
node teamroom-connector.mjs setup
```
순서대로 물어봅니다.
1. **팀룸 초대 링크**
2. **이름**: 크롬 확장에서 쓰는 이름과 같게 하면 한 칸에 모여 보입니다.
3. **공유할 팀 프로젝트 폴더**: 이 폴더 안에서 Claude Code나 Codex를 쓴 대화만 공유됩니다. 여러 개는 `;`로 구분하고, 모든 폴더를 공유하려면 `*`를 입력하세요.
4. **윈도우 켤 때 자동 실행**: Y를 고르면 이후로는 신경 쓸 필요가 없습니다.

## 2. 실행
자동 실행을 켰다면 다음에 윈도우를 켤 때부터 알아서 돌아갑니다. 바로 시작하려면 아래를 실행하세요.
```bash
node "%USERPROFILE%\.ai-teamroom\teamroom-connector.mjs" run
```

## 팀룸 패널 (옆에 뜨는 창)
설정할 때 `AI팀룸.exe` 경로를 넣으면(커넥터 파일과 같은 폴더에 두면 자동으로 찾습니다), 팀 폴더에서 Claude Code나 Codex 대화를 시작할 때 **화면 오른쪽에 팀룸 창이 자동으로 뜹니다.**
- **일반 창**입니다. 다른 창을 누르면 그 창이 앞으로 오고, 팀룸 창을 누르면 팀룸이 앞으로 옵니다. (항상 위에 두고 싶으면 **보기 → 항상 다른 창 위에**)
- 작업이 끝나면 작업표시줄 아이콘이 깜빡입니다.
- 창을 닫으면 그 세션에서는 다시 뜨지 않습니다. 직접 열려면 `node "%USERPROFILE%\.ai-teamroom\teamroom-connector.mjs" panel`
- 창 메뉴 **보기**에서 "항상 다른 창 위에"를 켜고 끌 수 있고, "화면 오른쪽에 붙이기"로 위치를 되돌릴 수 있습니다.
- 터미널이나 Codex 창은 `Win + ←`로 왼쪽에 붙이면 나란히 볼 수 있습니다.
- 팀원 피드백의 **↪ 피드백 반영**을 누르면 피드백이 복사됩니다. Claude Code·Codex 입력창에 붙여넣기(Ctrl+V) 하세요.
- 잘못 올라간 내 메시지는 메시지 오른쪽 위 **✕**로 지울 수 있고, 지운 메시지는 다시 올라오지 않습니다.

## 대화마다 공유 허가
같은 팀 폴더라도 **공유하기로 한 대화만** 올라갑니다.
- 팀 폴더에서 새 대화를 시작하면 화면 오른쪽 위에 **"이 대화를 팀룸에 공유할까요? [공유하기] [비공개]"** 창이 뜹니다. 고르기 전에는 아무것도 올라가지 않습니다.
- 팀룸 창 메뉴 **공유 → 대화 공유 관리…**에서 최근 대화의 공유를 켜고 끌 수 있습니다. 공유를 중지해도 이미 올라간 내용은 남습니다.
- **어떤 대화든 골라서 추가할 수 있습니다.** 같은 창에 최근 30일간의 Claude Code·Codex 대화가 모두 나옵니다(팀 폴더 밖의 대화, 커넥터 설치 전의 대화 포함). 기본은 비공개이고, **공유하기**를 누른 대화만 처음부터 전체가 올라갑니다. 위쪽 검색창으로 찾을 수 있습니다.
- 패널 앱 없이 쓰는 경우: `sessions`로 목록을 보고 `share <번호>` / `private <번호>`로 정합니다.

## 공유 규칙
- **팀 프로젝트 폴더**에서 나눈 대화 중 **허가한 대화만** 공유합니다. 다른 폴더의 개인 작업은 묻지도 않고 올라가지도 않습니다.
- 커넥터를 **설치한 뒤에 나눈 대화만** 올라갑니다. 예전 대화는 올리지 않습니다.
- 질문과 AI 답변 글만 올라갑니다. 도구 실행 내용, 파일 내용, 생각 과정은 올라가지 않습니다.
- 질문 하나에 AI가 중간중간 남긴 메모와 최종 답은 **하나의 답변으로 합쳐서** 보여줍니다.
- 인터넷이나 팀룸 서버가 끊기면 다시 연결됐을 때 이어서 올립니다.

## 기타 명령
| 명령 | 하는 일 |
|---|---|
| `status` | 현재 설정과 최근 공유 상태 보기 |
| `pause` / `resume` | 공유 잠시 멈추기 / 다시 시작 |
| `dry` | 최근 기록을 읽어서 질문·답변 개수만 보기 (아무것도 보내지 않음) |
| `setup` | 설정 다시 하기 (폴더 바꾸기 등) |
| `uninstall` | 윈도우 자동 실행 해제 |

예: `node "%USERPROFILE%\.ai-teamroom\teamroom-connector.mjs" status`

## Claude 앱의 "채팅" 탭 대화 공유

Claude 데스크톱 앱의 채팅 탭 대화는 PC에 파일로 남지 않아서, 커넥터가 **앱 화면에 열려 있는 대화**를 읽어 옵니다. (Windows 전용 · 읽기만 하고 클릭·입력은 하지 않음)

- 앱에서 채팅 대화를 화면에 열면, 팀룸 창 메뉴 **공유 → 대화 공유 관리…**의 "Claude 앱 채팅"에 그 대화가 나타납니다. (기본은 비공개)
- 그 대화에서 새 글을 주고받으면 **"이 대화를 팀룸에 공유할까요?"** 를 물어봅니다.
- 공유 중인 대화는 **앱 화면에 열려 있는 동안** 올라갑니다. 답이 나오기 전에 다른 화면으로 넘어갔다면, 그 대화를 다시 열 때 이어서 올라가요.
- 잘 읽히는지 확인: 채팅 대화를 화면에 띄워 둔 채로 `node teamroom-connector.mjs appread`
